# Experimentelle Module – Living Sculpture

Ausgelagerter Bereich des Projekts [Living Sculpture / Transparenzprojekt](https://achimmentzen.github.io/) von Achim Mentzen.

**Nur für Erwachsene.** Enthält das Erwachsenenmodul „Fremdbestimmter Orgasmus“ (80 Minuten), das Sexualität als künstlerisches Thema behandelt. Keine sexuelle Dienstleistung, keine expliziten Bilder.
